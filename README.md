# ChargePath

An EV trip planning website designed specifically for electric vehicle journeys in India.

## Features
- **Smart Route Planning:** Calculates optimal charging stops, driving time, charging time, and battery consumption.
- **Indian EV Support:** Pre-loaded battery and range profiles for Tata Tiago EV, Punch EV, Nexon EV, Mahindra XUV400, and MG ZS EV.
- **Live Charger Status:** Tracks available charging ports, CCS2 connector compatibility, and queue warnings.
- **Environmental Adjustments:** Estimates range considering summer A/C usage, rain, and payload.
- **Cost Analytics:** Displays charging costs in INR (₹) and tracks trip energy usage.

## Tech Stack
- **Frontend:** React / JavaScript, HTML, CSS
- **Tools:** Git, GitHub
